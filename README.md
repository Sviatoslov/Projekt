# Projekt

This repository contains a simple two-player Java game. One player controls using the WASD keys, while the other uses the arrow keys. The goal is to demonstrate a basic setup for a local multiplayer duel.

## Files

- `TwoPlayerGame.java` – the source code for the game implemented with Java Swing.

## Running the Game

To compile and run the game, make sure you have a JDK installed and execute the following commands from this directory:

```bash
javac TwoPlayerGame.java
java TwoPlayerGame
```

A window will appear where each player can move their square around the arena. When the squares collide, a message is printed to the console.
